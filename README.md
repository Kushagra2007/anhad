# ANHAD (अनहद) — Galgotias Literature Fest | GCET

An interactive, 3D royal book experience for the Galgotias Literature Fest at Galgotias College of Engineering & Technology (GCET), Greater Noida.

## 🕮 Features

- **3D Interactive Book**: True 3D perspective page-turning animations (front cover, spreads, colophon back cover).
- **Tactile Paper Sound Engine**: Multi-layered Web Audio synthesizer simulating crisp paper sliding friction, air whoosh, and soft landing settle, paired with serene Anhad Tanpura chimes.
- **Royal Brass Navigation**: Custom filigree navigation ribbon with small-caps typography, Devanagari labels, and custom vector icons.
- **Interactive Literary Sections**:
  - **Preface & Navarasa Poetic Wheel**: Explore the 4 classical Rasas (Shanta, Shringara, Veera, Adbhuta) with Hindi & English verses.
  - **Explore the Fest**: Filterable categories (Verse & Stage, Prose & Craft, Art & Panels) and interactive event charter modals.
  - **The Story So Far**: Wax-sealed chronological timeline with confirmed announcements.
  - **The Royal Mehfil**: Jharokha arch cards highlighting Mushaira, Dastangoi, and Samvaad.
  - **Ink Your Verse**: Interactive marginalia wall where readers dip a digital quill in 4 authentic inks, compose poetry, and generate downloadable souvenir bookmark PNGs.
  - **Your Chapter**: Vintage perforated ticket passes linking to Luma (Attendees) and Unstop (Participants).
  - **Campus Cartography**: Illustrated SVG campus schematic with interactive landmark pins.
  - **Help Centre**: Expandable FAQ accordion organized by topic.
- **Dual Reading Modes**: Seamless toggle between 3D Interactive Flipbook and Unfolded Continuous Scroll Manuscript.
- **Brass Diya Theme Toggle**: Light parchment mode vs. Midnight Mehfil dark mode with flickering brass lamp.
- **Ambient Desk Environment**: Golden floating dust motes canvas and rich wooden scholar's desk background.

## 🚀 Deployment

### GitHub Pages
1. Push this repository to GitHub.
2. Go to **Settings** > **Pages**.
3. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/<repo-name>/`.

### Vercel
1. Import this repository into Vercel (or run `vercel` via CLI).
2. Framework Preset: **Other** / **Static HTML**.
3. Deploy! Since it is a self-contained static site with zero dependencies, it deploys in seconds.
